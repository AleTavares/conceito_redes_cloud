Cultura DevOps

DevOps = Development + Operations
Cultura que elimina silos, promove colaboração contínua e responsabilidade compartilhada.

Modelo CALMS:

  • 🤝 Culture: Colaboração, responsabilidade compartilhada
  • 🤖 Automation: Automatizar tudo que é repetível
  • 📏 Lean: Lotes pequenos, feedback rápido
  • 📊 Measurement: Medir lead time, MTTR, taxa de falha
  • 📢 Sharing: Transparência e postmortems sem culpa

Pipeline CI/CD

Estágios:

Source → Build → Test → Release → Deploy → Monitor

CI (Integração Contínua):

  • Cada commit aciona build + testes
  • Detecção precoce de bugs
  • Feedback imediato

CD (Entrega/Implantação Contínua):

  • Código sempre pronto para deploy
  • Implantação automática em produção
  • Feature flags para controle

Ferramentas: Jenkins GitHub Actions GitLab CI CodePipeline

Infraestrutura como Código (IaC)

Definição: Gerenciar infraestrutura por meio de arquivos de configuração versionáveis, em vez de processos manuais.

Benefícios:

  • 🔄 Reprodutível: Mesmo código = ambientes idênticos
  • 📝 Rastreável: Histórico completo no Git
  • ✅ Consistente: Elimina configuration drift
  • 🔍 Auditável: Toda alteração passa por code review

Declarativa: "O que quero" (Terraform, CFn)

Imperativa: "Como fazer" (scripts, CDK)

GitOps

Conceito: Git é a única fonte de verdade para o estado desejado da infraestrutura e aplicações.

Princípios:

  • Todo o sistema descrito declarativamente
  • Estado desejado versionado no Git
  • Mudanças aprovadas aplicadas automaticamente
  • Agentes garantem convergência e autocorreção

Ferramentas: ArgoCD Flux

Vantagens: Auditoria completa, rollback = git revert, segurança (menor privilégio)

Blue-Green Deployment

🔵 Blue (Ativo)

Ambiente atual atendendo tráfego de produção

🟢 Green (Novo)

Nova versão deployada e validada

Após validação: Load balancer redireciona todo tráfego para Green.
Rollback: Instantâneo — basta apontar de volta para Blue.

Benefício principal: Rollback em segundos, zero downtime.

🛡️
9 / 14

Canary Deployment

Liberação gradual:

5% tráfego → 25% → 50% → 100%

  • Métricas monitoradas em cada etapa
  • Se taxa de erro sobe → rollback automático
  • Se saudável → aumenta tráfego gradualmente
Vantagem: Problemas detectados antes de impactar todos os usuários.

Observabilidade

Três Pilares:

  • 📝 Logs: Registros de eventos
  • 📊 Métricas: Latência, erro, throughput
  • 🔗 Traces: Caminho end-to-end

Ferramentas:

  • Prometheus métricas
  • Grafana visualização
  • Jaeger tracing
  • CloudWatch integrado AWS
  • Datadog multi-cloud

Resumo

Pontos-chave:
  • DevOps é cultura + automação + medição + compartilhamento
  • CI/CD: integração frequente + deploy automatizado
  • IaC: infraestrutura reprodutível, versionada e testável
  • GitOps: Git como fonte de verdade + reconciliação automática
  • Blue-Green: rollback instantâneo; Canary: validação gradual
  • Observabilidade = Logs + Métricas + Traces
  • Métricas DORA medem maturidade DevOps

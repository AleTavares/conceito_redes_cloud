O que são Modelos de Implantação?

Pergunta central: Quem possui, gerencia e acessa a infraestrutura?

Definição NIST (SP 800-145): Modelos que determinam como a infraestrutura de nuvem é provisionada e para quem é disponibilizada.

🔒 Nuvem Privada

Definição: Infraestrutura para uso exclusivo de UMA organização.

✅ Vantagens

  • Controle total sobre segurança
  • Isolamento físico
  • Customização para cargas específicas

⚠️ Limitações

  • Custo elevado (CapEx)
  • Escalabilidade limitada
  • Equipe especializada necessária

Tecnologias: VMware vSphere OpenStack Azure Stack Hub

🏢
5 / 14

☁️ Nuvem Pública

Definição: Infraestrutura aberta ao público, pertencente ao provedor.

✅ Vantagens

  • Economia de escala massiva
  • Elasticidade ilimitada
  • Modelo OpEx (pay-as-you-go)
  • Provisionamento instantâneo

⚠️ Considerações

  • Controle parcial
  • Multilocatário
  • Dependência do provedor

Provedores: AWS Azure Google Cloud

🌐
6 / 14

👥 Nuvem Comunitária

Definição: Infraestrutura compartilhada entre organizações com preocupações comuns.

✅ Vantagens

  • Custos divididos entre membros
  • Compliance setorial padronizado
  • Governança colaborativa

⚠️ Considerações

  • Menor flexibilidade
  • Coordenação entre membros
  • Escala limitada à comunidade

Exemplos: SINAPAD Cooperativas financeiras Nuvens governamentais

Critérios de Seleção

Perguntas-chave para a decisão:

  • 🔒 Os dados são altamente sensíveis?
  • 💰 Há orçamento para investimento inicial?
  • 📈 A demanda é previsível ou variável?
  • 🏛️ Existem regulamentações setoriais?
  • ⚡ Velocidade de inovação é prioridade?
Regra prática:
Sensível + regulação → Privada
Orçamento limitado + escala → Pública
Regulação setorial + custos compartilhados → Comunitária

Resumo

Pontos-chave desta aula:
  • Modelos de implantação definem QUEM acessa e COMO é provisionada
  • Privada = controle total + custo elevado
  • Pública = economia + elasticidade + responsabilidade compartilhada
  • Comunitária = compartilhamento setorial + compliance
  • A escolha depende de: custo, segurança, compliance, escalabilidade
